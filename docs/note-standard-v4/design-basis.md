# 设计依据与取舍

这组方向不是从热词反推问题，而是先看中文科普与工程内容怎样让陌生知识变得可进入。抽样中，[从日常玻璃追问材料原理](https://www.bilibili.com/video/BV1SDSiYEEL8/)说明“熟悉现象里的未知”适合作为入口；[把人形机器人的历史、瓶颈与路线放在同一叙事中](https://www.bilibili.com/video/BV14qdhY5EEb/)提示问题可以沿“过去怎样做—为何受阻—现在改了什么”展开；[从机器人比赛谈工程师成长](https://www.bilibili.com/video/BV1V9Nw6kE7t/)则提示学生更关心自己下一步能做什么、团队怎样协作。方向库吸收这些结构，不复制原标题，也不采用夸张胜负、倒计时或身份焦虑来换点击。

[Loewenstein 的信息缺口理论原文](https://www.contrib.andrew.cmu.edu/~gl20/GeorgeLoewenstein/Papers_files/pdf/PsychofCuriosity.pdf)提出：当人意识到“已知”和“想知道”之间有具体缺口时，好奇心会被唤起。这支持把问题写成可定位的小缺口，如反常现象、缺失参数、路线成立条件，而不是泛问“还有什么”。这是设计启发，不代表任意悬念都能提高学习效果。

[Harp 与 Mayer 的原始实验](https://doi.org/10.1037/0022-0663.90.3.414)显示，与学习目标无关但很有趣的细节可能削弱主旨记忆和迁移。因此，历史人物、职业、国家路线只在能解释概念、证据或工程决策时选用；轶事不能单独占一个问题。国家或机构比较必须基于任务、资源、标准、供应链等可查条件，不能写成民族优越或笼统排名；“进步”用可测指标表达，不编数字。

30 条是供模型按课程适配的候选池，每篇只取 3 条。优先组合一个现实应用、一个原理或工程取舍、一个与个人行动或开放问题有关的方向；若课程缺少人物史料、路线对照或职业材料，就跳过对应类别。论文主要支持问题设计的方向与风险边界，并未直接验证这 30 个中文模板的教学效果。
