# 听记阅读格式 study-v6

本格式适用于新整理和重新整理，优先于旧版格式约定。

- 首行 `# 知识主题`，不重复课程名或日期；章节用 `##`，具体子问题用 `###`，层级按内容需要设置。
- 一段或一条列表讲一个完整意思，给逐行阅读保留清楚的停顿；不写“按 Enter”等界面指令。保留必要机制、推导和例子，简短措辞不等于减少知识。比较表写明差异、优点、局限和适用情况；年表用“年份／事件／变化”；名词关系图的连线标注具体关系。只在对应内容需要时使用，年份须有可靠依据。
- 数学用 `$...$` 或独占行的 `$$`，兼容 KaTeX。图表放在对应知识旁：`mermaid` 图可表达具体过程、概念从属与组成关系，空间结构用白底黑线 `svg` 简图，从属关系可用 `tree`。箭头写清动作或关系，几何、箭头和公式保持一致。图应解释具体结构、过程或机制，不把已有列表、分类表再画一遍；名词图谱区分方法、组成模块、数据表示和学习过程，不在文末孤立堆图。
- 涉及多个层次的术语时，在相应解释后给一张名词关系图。用“属于／组成／作用于／产生”等明确关系连接实际概念，至少表达本篇需要分清的层次；单纯重画数据处理顺序不能代替这张图。图表已有的信息不再逐项复述。
- 每个适合视觉解释的主要主题都就近配图：机制画动作与状态变化，历史画时间线与事件联系，空间结构画对象的位置和连接；长稿通常安排 4–8 张有不同信息的图，随内容增减，短稿不凑数。图片与机制简图可并用，不能只在开头放一张图，后半篇全是文字。用 Mermaid 或 SVG 绘制准确的示意图，不用表格或术语列表代替图。
- 真实图片用资源目录的 `imagePath`：`![对象名称](/assets/note-resources/文件.webp)`，放在对应解释旁并说明看什么。正文还会按章节中的具体概念检索实物照片、地图或图解并自动署名；没有合适照片时保留机制示意图。不编造图片地址、照片细节或配图占位文字。外部链接用提供的真实 URL，搜索页名称注明“搜索”，不冒充某篇文章或视频。
- 需要解释的概念和关键关系在正文首次出现处标成 `[雅可比矩阵](concept:jacobian)`，覆盖承担主要定义、机制和公式的核心术语，不能只标一两个边缘词。标在原句里，不另列知识点，不给泛章节名挂链接。每个概念配一个能独立提问的具体问题及相关资料，点击显示复制按钮与 3 条知识索引；缺项由程序补平台搜索。正文标记与 study 的 concept id 一一对应。
- 文末“额外探索”只列 3 个直接链接，每行 `- [简短名称](URL)`。选不同的历史、现实应用、产品或工具，拓展正文；不重复推荐三段同主题教程，不加问题、描述或行动要求。资料不足用明确标注的搜索链接。
- `courseInfo` 只收明确的考核、作业、教材和时间安排，用短句；没有则留空。课程主题、知识目录、上节回顾、本节重点和视频清单不放进去。正文不出现课程信息、来源定位、待核对或生成检查记录。

末尾附隐藏的 `study` JSON 代码块：
```study
{"version":6,"concepts":[{"id":"jacobian","term":"雅可比矩阵","question":"雅可比矩阵如何把关节速度映射为末端速度？","links":[]}],"terms":[],"symbols":[],"courseInfo":[]}
```
用本篇内容替换示例；每个 concept 只写 id、term、question 和 links，未提供具体资料时 links 留空，由程序补齐搜索索引，不自行展开三平台搜索 URL。terms 选需要联动的术语及 group，symbols 选完整符号。无内容的数组留空。
正文较长时仍完整保留末尾的 3 项探索和 study 数据。
